# SignaVision 🤟

AI-powered American Sign Language (ASL) recognition system built using a custom Convolutional Neural Network (CNN).

## Overview

SignaVision is a portfolio-grade Artificial Neural Networks project that recognizes American Sign Language (ASL) alphabet signs using computer vision and deep learning.

The system will support both image-based and real-time webcam recognition.

## Planned Features

- ASL alphabet recognition
- Custom CNN architecture
- Image upload recognition
- Real-time webcam recognition
- Prediction confidence
- Sign-to-word formation
- Model comparison
- REST API
- Interactive React dashboard
- Model evaluation
- Automated testing
- Documentation
- Deployment
